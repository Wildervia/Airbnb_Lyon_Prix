LYON RENTAL INTELLIGENCE — WINDOWS

1. Décompressez ce ZIP dans Téléchargements.
2. Ouvrez PowerShell et placez-vous dans le dossier lyon_dashboard.
3. Installez les dépendances :
   & "C:\laragon\bin\python\python-3.10\python.exe" -m pip install -r requirements.txt
4. Démarrez :
   & "C:\laragon\bin\python\python-3.10\python.exe" -m streamlit run app.py
5. Ouvrez http://localhost:8501

Le fichier des avis est effectivement chargé et relié aux annonces pour les graphiques.
L'année du premier avis ne constitue pas une observation historique du prix.
